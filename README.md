# Le Malaga – guide de la maison

Guide web (FR / EN / ES) pour les invités de la maison du lac à Austin : mode d'emploi de la maison, photos, à faire autour de Magog et liste avant de partir.

Le site est publié automatiquement avec GitHub Pages à chaque modification de la branche `main`.

- Site : https://davecastonguay.github.io/le-malaga/
- Guides imprimables : `print/guide-fr.pdf`, `print/guide-en.pdf`, `print/guide-es.pdf`
- Autocollants QR à imprimer : `print/qr-autocollants.pdf`
